# atis

A weather map for code changes: what changed, how far it reaches, what evidence
covers it, and what to look at first. Fed by git, checkride and fallow. It
informs and never blocks.

**Status: `0.0.0` holds the name.** The command prints its version and exits.
The map is being built in the open at <https://github.com/robmclarty/atis>,
where `SPEC.md` is the design.

```bash
pnpm dlx atis --version
```

Apache-2.0.
